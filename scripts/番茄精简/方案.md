# 番茄小说 7.4.3.32 精简方案（只看小说 / 非 root / 不改包优先）

> 目标：只保留小说阅读链路（书架、阅读器、目录、AI 生图、插图、段评/章评、搜索、详情），
> 砍掉短剧/漫剧/漫画/直播/小游戏/小程序/金币红包/广告/推送/APM/小组件，降低后台 CPU、内存、流量与耗电。
> 前提：**不加正则替换**（该功能需要 hook 官方阅读器渲染链，难度另算，见文末）。

## 一、实测结论（基于用户提供的 7.4.3.32 APK 静态分析）

| 项 | 实测值 |
|---|---|
| 包名 / 版本 | `com.dragon.read` 7.4.3.32 |
| 解压体积 | 335 MB；25 个 dex（约 240 MB）；arm64 so 53.9 MB；res 2.2 万项 |
| 是否加壳 | **未整体加固**（dex 完整），但有腾讯 Tinker 热修、字节 Mira 插件化、metasec/argus 安全 SDK |
| 权限 | 224 个（含开机自启、忽略电池优化、WAKE_LOCK、查询全部应用、外部存储、定位、相机、录音、通讯录） |
| 组件 | activity 774、service 200、receiver 54、provider 46 |
| 后台进程 | `:push` `:pushservice` `:smp` `:miniapp0~4` `:minigame0~205` `:sandboxed_process0~9` `:plugin1` `:downloader` `:apm_memory_upload` `:sync` `:mist` `:uploadLogProcess` |
| 商业化模块 | 直播 SDK（`com.bytedance.android.livesdk.*` 5 个前台服务）、广告 IPC、小游戏/小程序、任务/幸运狗、FM 音频、预暖服务、高德定位、20+ 桌面小组件 |

**耗电结构判断**：阅读器本身很轻；常驻/唤醒几乎都来自上表的后台组件与推送长连接。因此"禁用组件 + 限制后台"就能拿到主要收益，不必改包。

## 二、三级方案

### Level 0：系统层（最安全，推荐先做）
- `am set-standby-bucket restricted`：系统级限制后台 CPU/网络/Job/闹钟
- `appops` 拒绝 `RUN_IN_BACKGROUND` / `START_FOREGROUND`
- 关闭通知权限（减少推送唤醒）
- 厂商 ROM 里关闭自启、后台活动、关联启动
- 预期：后台唤醒大幅减少，App 前台阅读不受影响

### Level 1：禁用纯后台/纯商业组件（非 root，`pm disable-user`）
- 推送：字节 push、小米/华为/OPPO/vivo 厂商通道、WsChannel 长连接
- 小游戏 / 小程序：`:minigame*`、`:miniapp*` 全部服务
- 直播：livesdk / openlive / livecast
- 广告：`AdIpcMainService`
- APM：`MemoryUploadService`
- Tinker / Mira 保活（`KeepAlive`、`StubService`）
- 预暖：`PreWarmService`
- 任务/金币：`CrossoverService`
- 桌面小组件 receiver（20+ 个）
- 预期：进程数、闹钟、Job 明显下降；阅读、评论、插图、AI 生图不受影响

### Level 2：可选激进（会影响部分功能，按需）
- Chromium 沙箱服务（禁后 H5 活动页/网页登录可能异常）
- 下载器（禁后"离线下载"不可用）
- 高德定位（禁后本地推荐可能变差）
- 音频/FM（禁后听书不可用）
- 短剧听模式保活

### Level 3：改包（可选，只为"藏入口"）
- apktool 反编译 → 删短剧/直播/金币 Activity 与入口 → 关 Tinker/Mira 热更 → 重签名
- 收益主要是界面干净，省电收益远小于 Level 0/1
- 风险：签名校验/风控、热更覆盖、每版重做

## 三、执行

```powershell

adb devices

# 1) 预演（不执行，只看命令）

# 2) 执行 Level 0 + Level 1
.\debloat.ps1 -Level 1

# 3) 出问题回滚（全部恢复）
.\debloat.ps1 -Rollback
```

脚本会逐个执行 `pm disable-user --user 0 com.dragon.read/<component>`，并打印成功/失败。
`KeepAlive$InnerService` 这类含 `$` 的组件已跳过（禁外层即可）。

## 五、风险与回滚

- `pm disable-user` 只改组件启用状态，**不删数据、不 root、可随时 `-Rollback` 恢复**。
- 若某个组件被禁用后 App 运行到它导致异常（启动崩溃/页面打不开），回滚该级别的组件即可。
- **不要禁用**：`com.dragon.read.misc.AuthenticatorService`、账户相关（depths account）、Room、WorkManager、主进程服务。
- 番茄更新后组件名可能变化，脚本按版本重新生成即可。

## 六、关于"正文正则替换"（本次不做）

- fqapp 的规则模型：`pattern / replacement / isRegex / enabled`，按顺序应用，**替换文本禁止换行**（保持段落结构），并维护"显示偏移 ↔ 源偏移"映射。
- 番茄侧必须 hook 在"章节正文解密后 → 渲染前"，且要重建段落索引，否则段评、插图、AI 生图会错位。
- 结论：独立工程，1~3 周定位 + 长期维护；等你确认要做再单独排期。

## 七、大我 B6（6 寸墨水屏 / Android 14）操作手册

### 7.1 连接设备
两种方式任选：
- **USB**：B6 设置 → 关于/系统 → 连点版本号开开发者选项 → 打开「USB 调试」→ PC 执行 `adb devices`。
- **无线（Android 11+）**：B6 设置 → 开发者选项 → 「无线调试」→ 配对码配对
  `adb pair <IP>:<配对端口>` → `adb connect <IP>:<无线调试端口>`。

### 7.2 先记基线（很重要，否则无法证明收益）
```powershell
adb shell dumpsys activity processes | findstr /i dragon   # 进程数
adb shell dumpsys alarm | findstr /i dragon               # 唤醒
adb shell dumpsys jobscheduler | findstr /i dragon        # 定时任务
adb shell dumpsys batterystats --reset
# 之后：待机 8 小时 + 阅读 30 分钟，再执行：
adb shell dumpsys batterystats com.dragon.read
```

### 7.3 执行
```powershell
.\debloat.ps1 -DryRun -Level 2   # 先预演，确认组件名能对上
.\debloat.ps1 -Level 1           # 执行（含 Level 0 的系统级限制）
```
执行后**从最近任务里划掉番茄再重开**，然后按 7.2 的方法再测一次，对比进程数/唤醒/耗电。

### 7.4 必须回归的功能（只看小说也要测）
- 冷启动能进书架
- 打开一本小说、翻 3 章、切章、跳转目录
- 评论区能加载、能回复
- 插图能显示
- AI 生图能触发（这是你唯一必须保留的"非阅读"功能，重点测）
- 退出重进，进度还在

### 7.5 如果某项坏了
```powershell
.\debloat.ps1 -Rollback   # 全部恢复
```
或者只恢复单个：
`adb shell pm enable --user 0 com.dragon.read/<组件名>`

### 7.6 这一步的预期
- 进程数：从 `:push`/`:smp`/`:miniapp*`/`:minigame*`/`:sandboxed_process*` 等一堆，降到只剩主进程（阅读器可能在主进程）。
- 闹钟/Job：推送心跳、APM 上传、小组件刷新基本消失。
- 待机耗电：明显下降；**阅读时的屏幕刷新不变**（这一步不动刷新，按你的要求）。
- 不影响：账号登录（账户服务未动）、阅读器、评论、插图、AI 生图（需回归验证）。
